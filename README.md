Этот проект демонстрирует технологию **P/Invoke** для вызова функций из динамической библиотеки (DLL), написанной на C++, внутри приложения на платформе .NET (C#).

### Структура проекта:
1. **C++ Core (Native):** Библиотека, реализующая высокопроизводительную обработку массивов данных (ввод, вывод, вычисление суммы элементов в диапазоне). Использует `DLL_EXPORT` для экспорта функций.
2. **C# Client (Managed):** Консольный интерфейс, который подключает внешнюю библиотеку через `[DllImport]` и управляет логикой приложения.

### Ключевые навыки:
- Маршалинг данных между C# и C++.
- Работа с соглашениями о вызовах (`CallingConvention.Cdecl`).
- Управление памятью при передаче массивов в неуправляемый код.
